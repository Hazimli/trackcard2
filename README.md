# TrackCard Investor Website

## Open
Open `index.html` in a modern browser.

## Included
- Investor-focused one-page Shark Tank style presentation
- Supplied TrackCard product photos
- Product demo MP4 generated from the supplied photos
- Interactive feature selector and simulated mobile app
- Interactive Ring Card / Lost Mode / View Location buttons
- Market validation visualization using the team's 100-person survey
- Business/prototype section using the presentation's RM99 per-unit prototype cost
- Team section based on the supplied presentation
- Responsive mobile layout
- Investor CTA and modal product film

## Source basis
The content is based on the supplied TrackCard Portfolio presentation. In particular:
- TrackCard is described as a smart tracking sticker/card-holder solution using Bluetooth and a mobile application.
- Functions include last detected location, buzzer activation and Lost Mode notifications.
- Survey: 100 respondents; 46.9% probably yes, 28.1% definitely yes, 21.9% not sure, with a small remainder in no categories.
- Prototype component cost breakdown totals RM99 per unit.
- Team: Imaan Ejaz Dave Sandhu (CEO), Muhammad Azfar Danisz (OM), Muhammad Hazim bin Ali (Technology), Afif Danish bin Shafari (Finance), Nur Qaisara Izzaty binti Mahathir (Marketing).

## Important
The website deliberately does not invent an investment amount or a final retail selling price because those figures were not supplied in the presentation. The investor CTA is therefore framed as an invitation to discuss partnership/funding.
